## 关键结论

- 正常 / 缺失信息 / 规则风险 / 时段冲突 / 硬性冲突 / 无可用时段 / 重复提交 / 保存失败 / 工具失败 / 执行上限均有实际输出与 Trace。
- 所有结果的 `published` 均为 `false`：系统没有任何发布工具，只能保存草稿。
- 相同请求重复执行命中同一 `draft_id`（`duplicate_existing`），时段变化后重规划会替换旧草稿（`superseded`）。
- 达到步数上限时返回 `task_status=incomplete` 与明确原因，不会伪造成功。
